# azure-resources
Collection of azure resource manager (ARM) templates written in bicep.

The issue summary workflow uses [Copilot CLI with the built-in Actions token](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli-in-actions). No repository secret is needed; in a personal repository, requests use the repository owner's Copilot entitlement.
